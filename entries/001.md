**Concepts:** DATE_PART, WHERE vs HAVING, GROUP BY, Aggregate function

## The question
Given a table of Facebook posts, for each user who posted at least twice in 2021,
write a query to find the number of days between each user’s first post of the year and last post of the year in the year 2021.
Output the user and number of the days between each user's first and last post.

## My query
```sql
SELECT user_id, DATE_PART('DAY' , MAX(post_date) - MIN(post_date)) AS days_between
FROM posts
WHERE DATE_PART('YEAR', post_date) = 2021
GROUP BY user_id
HAVING COUNT(post_id)>=2;
```
